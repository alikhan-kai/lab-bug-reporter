8. Интеграция отдельного компонента в произвольный интерфейс Standalone UI

Пример: сайт использует только кнопку записи экрана и собственный вызов Submit

Любой сайт может отключить встроенный виджет (widget: false) и встроить отдельный компонент в свою вёрстку с помощью фабрики LabReporter.createRecordButton(...):

// Код интеграции на стороне сайта: LabReporter.init({ projectKey: "pk_demo", widget: false }); LabReporter.identify({ id: "user-42", email: "student@sdu.edu.kz" }); const recordBtn = LabReporter.createRecordButton({ container: document.getElementById('my-record-slot'), microphone: true, onStart: () => console.log('Запись началась!'), onStop: () => console.log('Запись остановлена!') });
