# План работ

Состояние на 11 ноября 2026 по этапам ТЗ. Пункты с пометкой «проверить» в коде подробно не сверялись.

## Сделано

- Сервер принимает отчёт одним запросом, проверяет ключ, origin и лимиты.
- Отчёты и сведения о файлах сохраняются в Postgres, файлы и контекст в SeaweedFS.
- Файл проектов и CORS для каждого проекта.
- Единый JSON-формат ошибок.
- SDK собирает console, network, действия пользователя и окружение, снимает скриншот и записывает экран.
- Виджет в Shadow DOM и галерея компонентов.
- Отчёт со скриншотом и видео проходит из демо-сайта в браузере до базы и S3.
- Dev-realm Keycloak, проверка токенов, роли и видимые проекты, `GET /api/v1/me`, вход в dashboard.
- Dashboard API: список с фильтрами и пагинацией, карточка, контекст, файлы с `Range`, смена статуса, удаление.
- Dashboard на реальных данных: список, карточка, вкладки, статус и удаление по ролям.
- SDK: зависшие запросы, пустой `status` у упавших, маскировка только auth-заголовков, до 5 скриншотов,
  `submit()`, `startRecording({ microphone })`, Retry в панели, языки ru/en/kk.
- Весь стенд поднимается одной командой `docker compose up -d --build`: сервис, демо-сайт, Postgres, SeaweedFS, Keycloak.
